## Instructions

1. **Print:** Print the templates on heavy cardstock for durability.
2. **Color:** If using the black and white version, have the children color the armor pieces first.
3. **Cut:** Carefully cut out each piece.
4. **Assemble:** Use string, yarn, or staples to attach the pieces so the children can wear them. For example, attach a string to the Breastplate of Righteousness so it can hang around their neck.
